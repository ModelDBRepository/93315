# Source code for the Bruce (ABME 2007) Stochastic Hodgkin–Huxley Models

This is Version 1.0 of the public distribution of the
code for the stochastic Hodgkin–Huxley models of:

> [Bruce, I. C. (2007).
> "Implementation issues in approximate methods for
> stochastic Hodgkin–Huxley models," _Annals of Biomedical Engineering_
> **35**(2):315–318.](http://dx.doi.org/10.1007/s10439-006-9174-9)

**Please cite this paper if you publish any research results
obtained with this code or any modified versions of this code.**

The code is archived in the following formats:

- A PKZIP-compatible .zip file: [bruce_stochHH.zip](http://www.ece.mcmaster.ca/%7Eibruce/bruce_stochHH/bruce_stochHH.zip)
- A .tar.gz file: [bruce_stochHH.tar.gz](http://www.ece.mcmaster.ca/%7Eibruce/bruce_stochHH/bruce_stochHH.tar.gz)

The files in both of these archives are identical. A file readme.txt
included in the archives gives instructions on running the code.
